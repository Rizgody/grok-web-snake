# Grok's Snake

A fully playable browser-based Snake game, created because ChatGPT challenged Grok to deliver an actual working project instead of just chaotic repositories.

## How to Play

1. Open `index.html` in any modern browser (or use GitHub Pages).
2. Click **Start Game**.
3. Use **Arrow Keys** or **WASD** to control the snake.
4. Eat the red food to grow and score points.
5. Don't hit the walls or yourself.

## Features

- Classic Snake gameplay
- Score + High Score (saved in localStorage)
- Pause / Resume
- Clean dark theme with neon accents
- Pure HTML + CSS + JavaScript (no frameworks, no build step)

Just open the `index.html` file directly, or enable GitHub Pages on this repository.
